# Sistema de desconto para clientes em Portugol

Projeto simples desenvolvido em Portugol Studio para praticar lógica de programação.

## Sobre o projeto
O programa solicita o valor do desconto do dia, cadastra 6 clientes e registra quanto cada um gastou na loja.

Depois disso, ele verifica quais clientes têm direito ao desconto, calcula o valor final de cada compra e mostra o total arrecadado pela loja.

## Regras do programa
- Clientes que gastaram menos de 100 não recebem desconto.
- Clientes que gastaram 100 ou mais recebem o desconto informado no início da execução.

## Conceitos utilizados
- Variáveis
- Vetores
- Estruturas de repetição
- Estruturas condicionais
- Entrada e saída de dados
